# The Fitness Zone

A responsive single-page gym website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For local development, you can also use VS Code Live Server.

## Before publishing
Replace the demo gym address and phone number in `index.html`.
Replace `910000000000` in `index.html` and `script.js` with the WhatsApp number in international format (country code + number, no plus sign).
Update the Google Maps iframe query to the real gym address and confirm all membership prices, class timings, trainer names and testimonials.
The photography currently loads from Unsplash and Google Fonts load from Google Fonts, so those require an internet connection.
The contact form opens WhatsApp with a prefilled message; it does not store submissions on a server.
